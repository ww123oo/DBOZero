  python scripts/install_real_progress.py

or (if chunks are present):

  python scripts/assemble_build_output.py

(lang0/tbl row counts, not fixed 9 fake steps).

hanhua_v3/runtime/build_progress.py is already updated on main.

Then:
  dboc build --variant taiwan
